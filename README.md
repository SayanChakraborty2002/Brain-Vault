Brain Vault – AI-Powered Second Brain
Brain Vault is a full-stack productivity web application built with the MERN stack that helps users store, organize, and retrieve important content (like YouTube links, LinkedIn articles, tweets, images, and personal notes). It integrates AI search using Pinecone Vector DB and OpenAI (via Groq) to act as your personal second brain.

🚀 Features
🔐 User Authentication
Secure Sign Up / Sign In system with password validation using Zod.

🔗 Smart Content Saving
Save and categorize links from platforms like YouTube, LinkedIn, Twitter, and images.

🧠 Vector Embeddings & AI Integration
Stored content is transformed into embeddings using Pinecone Vector DB.

🔍 AI-Powered Search & Chat
Search queries are semantically matched with your saved content and sent to OpenAI through Groq to generate meaningful, context-aware answers.

💾 MongoDB Storage
All user data and links are securely stored in a MongoDB database.

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS

Backend: Node.js, Express.js

Database: MongoDB

Validation: Zod

AI & Search: Pinecone (Vector DB), OpenAI (via Groq)

Auth: JWT / Cookie-based authentication
